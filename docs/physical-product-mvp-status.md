# 액자·오브제 MVP 현황

기준일: 2026-07-27

최우선 목표: 실제로 돈을 내고 사고 싶은 품질의 액자 1개와, 실제 출력 가능한
오브제 1개를 주문하여 제작·배송·개봉까지 검증한다.

## 전체 상태

| 영역 | 기획 | 디지털 샘플 | 생산 파일 | 실물 주문 | 품질·배송 검증 |
|---|---:|---:|---:|---:|---:|
| 액자 | 완료 | 완료 | 1차 완료 | 미실시 | 미실시 |
| 3D 오브제 | 1차 완료 | 1차 완료 | 미완료 | 미실시 | 미실시 |

## 1. 액자

### 완료

- 비방서의 오행·에너지 모드·수호 동물을 이미지로 변환하는 자동 라우터
- 추상 수호형, 현대 민화형, 수묵형, 기하 토템형 4개 작품군
- 스타일 선택 없이 분석 결과가 작품군을 자동 결정하는 로직
- 30종 궁극 프롬프트 테스트
- 수호 동물 10종 테스트
- 동물 가시성을 높인 3종 재검증
- 스타일별 3종, 총 12종 비교
- A3 무광 파인아트 출력 기준과 QC 기준
- 첫 A3 후보의 300 PPI, 3mm 도련 PNG·JPG·인쇄 PDF 생성
- 내부용 `Room Guardian Frame`과 외부용 `Site Guardian Frame` SKU
- 액자 주문 문의·결제 UI

### 현재 첫 실물 후보

- 현대 민화형 토끼
- 목 기운 보완 / 정화 모드
- A3 세로형
- 무광 파인아트지
- 내추럴 오크 또는 매트 월넛 프레임

생산 파일:

- `output/pdf/first-frame-test/pungsoo-minhwa-rabbit-wood-purify-a3-bleed3mm-print.pdf`

### 미완료

- 실제 인쇄소 또는 주문 제작 업체 선정
- 첫 액자 결제와 주문
- 종이·잉크·프레임 색상 실물 확인
- 어두운 영역 뭉침, 동물 인식도, 재단 안전 영역 검수
- 포장과 파손 여부 확인
- 국내 배송비·제작 기간 기록
- 해외 출력·배송 파트너 비교
- 실물 촬영과 상품 상세페이지용 공간 목업

### 판단

액자는 지금 바로 첫 실물 주문 단계로 넘어갈 수 있다. 이미지 기획을 더 늘리기보다
현재 후보를 실제 출력해 화면과 종이의 차이를 확인하는 것이 우선이다.

## 2. 3D 오브제

### 완료

- 사용자 오행과 띠 궁합을 반영한 수호 동물 선정 구조
- 비방화와 동일한 수호 동물을 오브제에도 사용하는 일관성 원칙
- 동물, 소재·색상, 자세, 추천 이유, 배치 위치 데이터 구조
- 저폴리 수호 동물의 3D 제품 렌더 이미지 생성
- 내부용 `Desk Guardian Totem`과 외부용 `Gate Guardian Totem` SKU
- 소형·중형·대형 및 직접 치수 입력 주문 UI
- 서양 시장용 오브제 후보 8개와 MVP 우선순위

### 미완료

- 실제 3D 메시 생성
- STL·3MF·OBJ 생산 파일
- 바닥 접지, 벽 두께, 오버행, 서포트와 최소 부재 두께 검증
- 동물별 파손 위험이 있는 귀·뿔·꼬리 단순화
- FDM, SLA, SLS 방식 비교
- 소재와 후가공 샘플
- 출력 단가·무게·제작 시간 계산
- 첫 테스트 출력
- 도색, 명판과 포장 방식
- 낙하·파손·국제배송 테스트
- 상품 사진과 크기 비교 사진

### 첫 MVP 권장 사양

- 제품: Personal Guardian Totem
- 크기: 높이 8~12cm
- 조형: 하나의 연속된 바닥과 안정적인 중심
- 형태: 동물은 알아보되 귀·뿔·꼬리는 두껍고 짧게 단순화
- 색상: 먹빛 검정, 따뜻한 황동, 광물성 백색 중 3종 이하
- 개인화: 본체 전체를 다시 만들지 않고 교체 가능한 이름·오행 명판 사용
- 디지털 연결: 전자 부품 대신 비방서로 연결되는 QR 카드

### 판단

오브제는 아직 ‘3D처럼 보이는 이미지’ 단계다. 실제 출력 가능한 3D 제품 단계로
넘어가려면 먼저 동물 하나를 정해 메시 설계와 출력 테스트를 해야 한다.

## 3. 다음 실행 순서

1. 준비된 A3 PDF로 액자 1개를 실제 주문한다.
2. 도착 후 색, 재단, 프레임, 포장과 사진발을 평가한다.
3. 오브제 첫 동물을 하나로 고정한다.
4. 8~12cm 출력용 메시와 탈착 명판을 설계한다.
5. 동일 디자인을 FDM과 레진 방식으로 각각 1개씩 출력한다.
6. 액자와 오브제를 한 공간에 놓고 세트 상품 사진을 촬영한다.
7. 원가·배송비·불량률을 반영해 국내·해외 가격을 확정한다.
