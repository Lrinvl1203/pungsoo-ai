# 신규 사업장 PUNGSOO AI 실제 적용 파일럿

Last updated: 2026-08-11

Status: `MINIMAL INTAKE DESIGNED`, 통합 빠른 분석 구현 전

파일럿 ID: `PILOT-BIZ-001`

실제 주소, 생년월일, 전화번호, 얼굴이 나온 사진과 EXIF 원본은 Git에
기록하지 않는다. 앱이나 승인된 임시 입력 경로에서만 사용하고 문서에는
익명화된 결과와 측정값만 남긴다.

## 1. 파일럿 목적

새 사업장을 첫 실제 사업장 사례로 사용해 다음을 검증한다.

1. 최소 입력으로 외부 입지와 내부 공간 분석이 가능한가
2. 비방서의 `Remedy Identity`가 비방화와 오브제에 일관되게 반영되는가
3. 액자·오브제가 실제 인테리어와 생산 조건에 맞는가
4. 사용자의 심리적 만족과 운영 관찰을 분리해 기록할 수 있는가

운영 지표는 관찰 기록이며 풍수 처방이 매출·계약·방문을 만들었다는 인과
증거로 사용하지 않는다.

## 2. 사용자 입력 계약

기본 입력은 네 가지뿐이다.

1. 필수 사진 1장: 현관 안쪽에서 핵심 공간 전체가 보이게 촬영
2. 선택 사진 1장: 현관·카운터·창과 고객 동선 중 가장 중요한 곳
3. 위치: 현재 위치 자동 확인 또는 주소 검색과 지도 핀 확인
4. 방위: 실제 현관에서 바깥을 보는 방향을 지도 화살표 또는 기기 센서로 한 번 확인

외관 여러 장, 좌·우 도로 사진, 휴대폰 나침반 반복 측정, 평면도, 업종과
고민의 장문 입력, 생년월일과 성별을 선행 요구하지 않는다.

### 시스템이 자동으로 하는 일

- 위치·위성지도로 도로, 건물 배치, 녹지, 수변과 주변 형기를 분석한다.
- 사진 1~2장으로 문·창·가구·채광·핵심 동선과 공간 용도를 추론한다.
- 사진이 한 장이면 보이지 않는 구조를 단정하지 않고 `초견 분석`으로 표시한다.
- 같은 현관 외향 방위를 외부·내부 분석의 공통 방위 메타데이터로 사용한다.
- 업종·공간 목적은 사진에서 추론하고 결과에서 사용자가 한 번에 수정할 수
  있게 한다. 수정 전에도 분석을 막지 않는다.
- 사주 정보가 없으면 공간 기반 `Space Guardian`을 생성한다. 사용자가 결과
  후 개인화를 원할 때만 생년 정보로 `Personal Guardian`을 추가한다.

### 운영자 QA 자료

파일럿 정확도 검증이 필요하면 운영자가 별도로 외관 사진, 나침반 반복값과
평면 스케치를 수집할 수 있다. 이 자료는 사용자 기본 플로우의 필수 입력이
아니며 분석 결과를 가린 뒤 사후 비교하는 QA 근거다.

### 설치 전 기준 사진

- 첫 사진의 촬영 위치와 카메라 높이를 표시한다.
- 같은 위치·배율·시간대·조명으로 설치 후 사진을 반복 촬영한다.
- 사용자가 추가 사진을 다시 찍지 않아도 최초 입력 사진을 기준선으로 쓴다.

## 3. 실행 순서

### A. 최소 입력

1. 사진 1장을 올리고 필요하면 1장을 추가한다.
2. 현재 위치 또는 주소 검색으로 지도 핀을 확인한다.
3. 현관이 바깥을 보는 방향을 한 번 확인한다.
4. `빠른 사업장 분석`을 실행한다.

### B. 내부·외부 동시 처리

한 번의 입력을 서버에서 두 분석 작업으로 분기한다.

- `Site Guardian`: 위치·위성지도·공통 방위
- `Room Guardian`: 사진 1~2장·공통 방위

외부와 내부는 별도 분석으로 유지한다. 점수를 평균내 하나의 총점으로 만들지
않고 공통 처방과 충돌 처방을 비교한다.

| 확인 항목 | 외부 Site | 내부 Room | 최종 적용 |
|---|---|---|---|
| 부족·과잉 오행 |  |  | 공통 우선, 충돌은 위치별 분리 |
| 에너지 모드 |  |  | 외부·내부 각각 유지 |
| 수호동물 |  |  | 세트 제품 일관성 검토 |
| 배치 위치 |  |  | 현관과 데스크 분리 |
| 방향 근거·신뢰도 |  |  | 추정과 실측을 구분 |

현재 앱은 내부와 외부를 별도로 실행한다. `사진 1~2장 + 위치 + 방위` 한 번으로
두 결과를 생성하는 통합 빠른 분석 UI와 오케스트레이션은 구현 전이다. 구현
완료 전 파일럿에서는 같은 최소 입력을 두 기존 흐름에 재사용하되 사용자에게
중복 입력을 요구하지 않는 운영 보조 방식으로 테스트한다.

### C. Remedy Identity 고정

비방서가 확정되면 이미지 생성 전에 다음 값을 저장한다.

- 분석 ID와 `internal`/`external`
- 목표 오행과 상태
- 에너지 모드와 비방 목적
- 수호동물
- 주조색·보조색
- 자세·형태 언어
- 설치 위치
- 방향 데이터의 측정 방식과 신뢰도

이미지와 오브제 프롬프트는 이 값을 공유하며 생성 후 일치 여부를 심사한다.

### D. 단계별 설치

1. 1단계: 가구·동선·조명처럼 비용이 낮은 내부 처방
2. 2단계: 비방화 미니 액자 또는 벽 액자
3. 3단계: 데스크 또는 현관 수호 오브제

각 단계 사이에 최소 7일을 두고 최초 사진과 같은 위치에서 기록을 남긴다.
오픈 일정상 설치 전 영업 기준기간이 없으면 첫 주를 운영 기준선으로 삼고,
그 전에 적용한 항목은 성과 비교가 아닌 제품·공간 적합성만 평가한다.

## 4. 평가표

### 즉시 평가: 1~5점

- 입력이 실제로 1분 안에 끝나는가
- 비방서가 이해되고 실행 가능한가
- 비방화와 오브제가 같은 개인 처방으로 느껴지는가
- 동물 종과 의미가 알아보이는가
- 한국적이지만 전통 기념품처럼 보이지 않는가
- 공간 인테리어에 어울리고 돈을 내고 소유하고 싶은가

### 제품·생산 평가

- 오브제가 흔들리지 않고 자립하는가
- 날카로운 모서리와 파손 위험이 없는가
- 조형 디테일이 8~12cm에서도 보이는가
- 색과 황동 포인트가 액자와 한 세트로 보이는가
- 현관형이면 걸이, 문 간섭, 소음과 낙하 위험이 없는가

### 운영 관찰

- 일 방문 또는 상담 수
- 문의→계약 또는 방문→구매 전환
- 객단가와 재방문
- 대표자의 집중감·안정감·공간 만족도 1~5점
- 고객이 먼저 액자나 오브제를 언급한 횟수와 실제 반응 문장

매출·계약 지표는 계절, 광고, 가격, 오픈 효과와 함께 기록한다. 풍수 처방과
인과관계가 있다고 단정하지 않는다.

## 5. 권장 일정

| 시점 | 작업 |
|---|---|
| D-7~D0 | 최소 입력 1~2장과 위치·방위 확인, 설치 전 기준 사진 |
| D1 | 외부·내부 분석과 비방서 저장 |
| D2 | 두 분석 비교, Remedy Identity 확정 |
| W1 | 저비용 공간 처방 적용·관찰 |
| W2 | 비방화 설치·관찰 |
| W3 | 오브제 설치·관찰 |
| W4 | 사용자·고객 반응과 생산성 검토 |
| W6~W8 | 후속 설문, 장기 외관·내구성·운영 기록 검토 |

## 6. 완료 기준

- 사진 1~2장·위치·방위 한 번의 입력으로 외부와 내부 결과가 생성됨
- 외부와 내부 분석 결과 및 입력 근거가 분리돼 저장됨
- 추가 입력 없이도 불확실성이 초견·신뢰도로 정직하게 표시됨
- 하나 이상의 Remedy Identity가 확정됨
- 액자와 오브제가 동일 정체성을 공유함
- 최초 입력 사진과 설치 후 고정 사진이 있음
- 제품 만족도·실행 가능성·생산 위험이 기록됨
- 사업 지표와 개인 경험이 인과 주장 없이 기록됨
