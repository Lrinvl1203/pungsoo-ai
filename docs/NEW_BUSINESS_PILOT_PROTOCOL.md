# 신규 사업장 PUNGSOO AI 실제 적용 파일럿

Last updated: 2026-08-11

Status: `READY FOR INTAKE`

파일럿 ID: `PILOT-BIZ-001`

실제 주소, 생년월일, 전화번호, 얼굴이 나온 사진과 EXIF 원본은 Git에
기록하지 않는다. 앱이나 승인된 임시 입력 경로에서만 사용하고 문서에는
익명화된 결과와 측정값만 남긴다.

## 1. 파일럿 목적

새 사업장을 첫 실제 사업장 사례로 사용해 네 가지를 구분해 검증한다.

1. 외부 입지와 내부 공간 분석이 실제 입력에서 이해 가능한가
2. 비방서의 `Remedy Identity`가 비방화와 오브제에 일관되게 반영되는가
3. 액자·오브제가 실제 인테리어와 생산 조건에 맞는가
4. 사용자의 심리적 만족과 사업 운영 지표가 어떻게 변하는가

4번은 관찰 기록이며 풍수 처방이 매출·계약·방문을 만들었다는 인과 증거로
사용하지 않는다.

## 2. 시작 전에 받을 자료

### 사업 정보

- 업종과 주요 고객
- 신규 오픈 예정일 또는 실제 영업 시작일
- 가장 중요한 목표 1~2개: 유입, 체류, 계약, 재방문, 집중, 안정 등
- 대표자 사주 정보는 선택 입력이며 Git에 저장하지 않는다

### 외부 입지

- 정확한 주소를 앱에서 검색하고 지도 핀을 직접 확인
- 건물 전체 정면 사진 1장
- 접근 도로와 주변 흐름이 보이는 좌·우 사진 각 1장
- 실제 사용하는 대문·현관 정면 사진 1장
- 현관에서 바깥을 바라본 휴대폰 나침반 값 3회

현재 서비스의 외부 분석 런타임 입력은 주소·지도 핀·선택적 방향
화살표다. 외관·현관 사진과 나침반 값은 아직 자동 분석 입력이 아니므로
파일럿 교차 검증 자료로만 별도 보관한다. 지도 화살표는 계속 `low` 신뢰도의
추정 방위로 표시한다.

### 내부 공간

앱의 최대 3장 입력에 맞춰 다음 순서로 촬영한다.

1. 현관 안쪽에서 본 전체 공간
2. 가장 중요한 영업 지점: 카운터, 상담석, 작업 데스크 중 하나
3. 창·문·주요 고객 동선이 함께 보이는 반대편 시점

가능하면 간단한 평면 스케치에 현관, 창, 화장실, 카운터, 좌석과 북쪽을
표시한다. 현재 평면도는 런타임 입력이 아니라 결과 교차 검증용이다.

### 설치 전 기준 사진

- 네 모서리와 천장·바닥이 보이는 고정 카메라 위치를 정한다
- 카메라 높이, 렌즈 배율, 촬영 시간과 조명을 기록한다
- 같은 위치에서 설치 전·후 사진을 반복 촬영한다

## 3. 실행 순서

### A. 외부 입지 분석

1. `/analyze`에서 외부 입지를 선택한다.
2. 주소 검색 후 실제 건물의 핀을 확인한다.
3. 위성지도에서 현관 외향 화살표를 지정한다.
4. 휴대폰 나침반 3회 중앙값과 지도 화살표의 차이를 기록한다.
5. `Site Guardian` 비방서를 저장한다.

### B. 내부 공간 분석

1. 동일 사업장 내부 사진 3장을 업로드한다.
2. 업종, 주 사용 목적과 가장 큰 고민을 입력한다.
3. `Room Guardian` 비방서를 저장한다.

외부와 내부는 별도 분석으로 유지한다. 점수를 평균내 하나의 총점으로 만들지
않고, 공통 처방과 충돌 처방을 아래처럼 비교한다.

| 확인 항목 | 외부 Site | 내부 Room | 최종 적용 |
|---|---|---|---|
| 부족·과잉 오행 |  |  | 공통 우선, 충돌은 위치별 분리 |
| 에너지 모드 |  |  | 외부·내부 각각 유지 |
| 수호동물 |  |  | 세트 제품 일관성 검토 |
| 배치 위치 |  |  | 현관과 데스크 분리 |
| 방향 근거·신뢰도 |  |  | 추정과 실측을 구분 |

### C. Remedy Identity 고정

비방서가 확정되면 이미지 생성 전에 다음 값을 JSON으로 저장한다.

- 분석 ID와 `internal`/`external`
- 목표 오행과 상태
- 에너지 모드
- 비방 목적
- 수호동물
- 주조색·보조색
- 자세·형태 언어
- 설치 위치
- 방향 데이터의 측정 방식과 신뢰도

이미지와 오브제 프롬프트는 이 값을 공유하며 생성 후 자동·수동 심사에서
일치 여부를 확인한다.

### D. 단계별 설치

한 번에 모든 것을 바꾸면 무엇이 공간 경험을 개선했는지 알 수 없다.

1. 1단계: 가구·동선·조명처럼 비용이 낮은 내부 처방
2. 2단계: 비방화 미니 액자 또는 벽 액자
3. 3단계: 데스크 또는 현관 수호 오브제

각 단계 사이에 최소 7일을 두고 같은 위치에서 사진과 사용 기록을 남긴다.
오픈 일정상 설치 전 영업 기준기간이 없으면 첫 주를 운영 기준선으로 삼고,
그 전에 적용한 항목은 성과 비교가 아닌 제품·공간 적합성만 평가한다.

## 4. 평가표

### 즉시 평가: 1~5점

- 비방서가 이해되는가
- 처방이 실제로 실행 가능한가
- 비방화와 오브제가 같은 개인 처방으로 느껴지는가
- 동물 종과 의미가 알아보이는가
- 한국적이지만 전통 기념품처럼 보이지 않는가
- 공간 인테리어에 어울리는가
- 실제로 돈을 내고 소유하고 싶은가

### 제품·생산 평가

- 오브제가 흔들리지 않고 자립하는가
- 날카로운 모서리와 파손 위험이 없는가
- 조형 디테일이 8~12cm에서도 보이는가
- 색과 황동 포인트가 액자와 한 세트로 보이는가
- 현관형이면 걸이, 문 간섭, 소음과 낙하 위험이 없는가

### 운영 관찰

- 일 방문 또는 상담 수
- 문의→계약 또는 방문→구매 전환
- 객단가와 재방문
- 대표자의 집중감·안정감·공간 만족도 1~5점
- 고객이 먼저 액자나 오브제를 언급한 횟수와 실제 반응 문장

매출·계약 지표는 계절, 광고, 가격, 오픈 효과와 함께 기록한다. 풍수 처방과
인과관계가 있다고 단정하지 않는다.

## 5. 권장 일정

| 시점 | 작업 |
|---|---|
| D-7~D0 | 입력 수집, 고정 위치 설치 전 사진, 가능하면 기준 운영 기록 |
| D1 | 외부·내부 분석과 비방서 저장 |
| D2 | 두 분석 비교, Remedy Identity 확정 |
| W1 | 저비용 공간 처방 적용·관찰 |
| W2 | 비방화 설치·관찰 |
| W3 | 오브제 설치·관찰 |
| W4 | 사용자·고객 반응과 생산성 검토 |
| W6~W8 | 후속 설문, 장기 외관·내구성·운영 기록 검토 |

## 6. 완료 기준

- 외부와 내부 분석 결과 및 입력 근거가 분리돼 저장됨
- 하나 이상의 Remedy Identity가 확정됨
- 액자와 오브제가 동일 정체성을 공유함
- 설치 전·후 고정 사진이 있음
- 제품 만족도·실행 가능성·생산 위험이 기록됨
- 사업 지표와 개인 경험이 인과 주장 없이 기록됨
- 다음 사용자에게 반복할 수 있는 입력·생성·설치·평가 절차가 남음
