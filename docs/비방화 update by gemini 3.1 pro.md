기운이 탁하고 흉한 공간에는 **'강력한 정화와 보호(결계)'**의 에너지가 필요하고, 이미 기운이 좋은 공간에는 **'부와 운을 극대화(증폭)'**하는 화려한 에너지가 필요합니다.

🧩 완벽한 동적 프롬프트 조립 공식 (Dynamic Prompt Formula)

백엔드(api/generate-visuals.ts)에서 최종적으로 fal.ai에 보낼 프롬프트를 3개의 블록으로 나누어 조립합니다.

[ 1. Gemini가 창작한 고유 스토리 ] + [ 2. 시스템이 강제하는 오행 규칙 ] + [ 3. 화풍 및 퀄리티 지시어 ]

블록 1: 고유 스토리 (Dynamic)

  - 출처: Gemini가 생성한 remedy_art.image_generation_prompt
  - 역할: 공간의 고민(재물, 건강 등)과 유저의 사주에 맞춘 세상에 하나뿐인 상징물과 상황 묘사. 매번 완전히 바뀝니다.

블록 2: 오행 규칙 (System Injection)

  - 출처: 앱 내 하드코딩된 오행 매핑 테이블
  - 역할: Gemini가 어떤 엉뚱한 스토리를 쓰더라도, 결핍된 기운의 색상과 형태가 무조건 포함되도록 강제합니다.

블록 3: 화풍 & 퀄리티 (Style Template)

  - 출처: 유저가 선택한 스타일(모던, 레트로 등)과 공간 점수에 따른 하이엔드 화풍 템플릿(앞서 제안한 10가지 중 하나)
