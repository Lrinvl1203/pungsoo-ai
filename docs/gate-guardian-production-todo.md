# 현관 명태식 수호동물 오브제 발주 TODO

상태: `DEFERRED`

우선순위: 사용자 재개 요청 시 바로 진행

목적: 현재 수호동물 STL을 현관에 명태 오브제를 거는 것처럼 사용할 수 있는
실물 샘플로 제작하고, 걸이 안정성과 상품성을 검증한다.

## 1. 현재 준비된 파일

- 디자인: 미네랄 릴리프 수호동물
- 출력 후보 STL:
  `artifacts/3d-ai/triposr-gate-mineral-v1/gate-guardian-mineral-ai-170x98x12mm-v1.stl`
- 규격: 97.761 × 170 × 12mm
- 메시: 35,608 triangles, 단일 solid, watertight
- 예상 체적: 55.352cm³
- 제작 파이프라인: `docs/3D_AI_STL_PIPELINE.md`

## 2. 추천 1차 발주 사양

- 수량: 1개
- 용도: 현관문 또는 현관 벽 걸이 테스트
- 출력 방식: FDM
- 재료: PETG 우선, 비교 견적이 크게 비싸면 PLA+
- 출력 품질: 0.16~0.20mm 레이어
- 색상: 무광 차콜 또는 웜그레이 단색
- 채움: 20~30%
- 외벽: 3~4겹
- 후가공: 서포트 제거와 기본 표면 정리만
- 도색: 첫 샘플은 생략하고 형상과 강도를 먼저 검증
- 목표 예산: 배송 포함 약 3만~5만원

## 3. 발주 전 모델 보정

- [ ] AI가 추정한 뒷면을 평탄화해 문에 안정적으로 닿게 하기
- [ ] 위쪽 걸이 구멍 실제 지름 측정
- [ ] 걸이 구멍 둘레 두께 3mm 이상 확보
- [ ] 얇은 뿔·꼬리·모서리 최소 두께 1.6mm 이상 확보
- [ ] 현관문 흠집 방지용 EVA/실리콘 패드 부착면 확보
- [ ] 줄에 거는 방식과 직접 후크에 거는 방식을 모두 검토
- [ ] 최종 STL을 다시 watertight·단일 solid로 검증

## 4. 실제 견적 순서

1. 3DFARM 자동 견적에 최종 STL 업로드
2. PLA+와 PETG 가격 비교
3. 17cm 1개, 0.16~0.20mm, 20~30% infill로 견적 저장
4. WOW3D 또는 FabCube에서 동일 조건으로 한 번 더 비교
5. 배송비와 예상 제작일 포함 총액 비교
6. 가장 적합한 업체 장바구니 또는 주문서까지 입력
7. 결제 직전 사용자에게 최종 사양과 총액 확인
8. 승인 후 결제·발주

## 5. 수령 후 테스트

- [ ] 현관문을 여닫을 때 흔들림·충돌·소음 확인
- [ ] 24시간, 3일, 7일 걸이 유지
- [ ] 걸이 구멍 균열과 본체 휨 확인
- [ ] 문 표면 스크래치와 이염 확인
- [ ] 1m 높이 낙하 테스트
- [ ] 실제 현관에서 정면·측면·원거리 사진 촬영
- [ ] 크기, 무게, 존재감, 색상에 대한 사용자 반응 기록
- [ ] 2차 버전에서 뒷면 패드·줄·고리·색상 보정

## 6. 판매용으로 확장할 때

- 기본형: 단색 PETG/FDM
- 컬러형: 단색 출력 후 오행 팔레트 부분 도색
- 프리미엄형: 레진 마스터 또는 멀티컬러 출력
- 걸이 옵션: 전통 매듭끈, 미니멀 금속링, 자석 보조 고정
- 사이즈 옵션: 미니 100mm / 기본 170mm / 대형 240mm
