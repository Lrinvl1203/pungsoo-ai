# 비방화 궁극 프롬프트 30종 통제 테스트

테스트일: 2026-07-25  
목적: 오행 처방의 의미를 유지하면서도 설명 없이 구매 가능한 액자 작품을 만드는 생성 문법을 찾는다.

## 테스트 설계

동일한 3:4 세로 인쇄 마스터 조건에서 아래 조합을 전부 생성했다.

- 오행 5종: 목, 화, 토, 금, 수
- 에너지 모드 3종: 정화, 순환, 증폭
- 표현 방식 2종:
  - `tactile`: 한지, 광물 안료, 먹, 석회, 마른 붓질 중심
  - `graphic`: 큰 색면, 선명한 위계, 제한된 반투명 겹침 중심

총 `5 × 3 × 2 = 30개`다.

## 핵심 결론

### 1. 형식 선점이 금지어보다 강하다

“불꽃을 그리지 마라”보다 “둥근 직사각 면 5개, 뾰족한 끝 0개, 방사형 중심 0개”가 훨씬 안정적이었다.

### 2. 최고의 기본 화풍은 혼합형이다

- 구도: `graphic` 방식의 큰 면, 정확한 개수, 명확한 여백과 위계
- 표면: `tactile` 방식의 한지 섬유, 광물 안료, 먹 번짐, 석회 질감

즉, **그래픽 구조 70% + 물성 30%**가 기본값이다.

### 3. 오행 이름을 최종 렌더러에 넘기지 않는다

진단 단계에서는 오행을 사용하되, 이미지 모델에는 색면·절단·곡률·겹침·틈 같은 조형 언어만 전달한다. 이것이 나무, 불꽃, 파도, 동전 같은 문자 그대로의 이미지 누출을 줄인다.

### 4. 색 비율과 암부 비율은 사후 검사한다

이미지 모델은 “어두운 면적 10% 이하” 같은 수치를 정확히 지키지 않는다. 이번 결과에서 밝기 `0.12` 미만 픽셀은 다음처럼 확인됐다.

- 25번: 10.6%
- 28번: 15.1%
- 29번: 13.6%
- 30번: 8.6%

따라서 프롬프트는 방향을 잡고, 최종 후보는 픽셀 검사와 인쇄 프루프로 걸러야 한다.

## 실물 액자 후보

첫 인쇄 비교는 아래 3장을 권장한다.

1. `04-wood-circulate-graphic`: 가장 보편적인 거실 상품성
2. `16-earth-circulate-graphic`: 우드톤·내추럴 인테리어 적합성
3. `30-water-amplify-graphic`: 강한 색상의 판매 가능성과 암부 재현 테스트

세 장 모두 최종 인쇄 전 4K 재생성 또는 구도 보존 업스케일이 필요하다.
