# 비방서 → 비방화 샘플 3종

세 이미지 모두 액자·벽·방을 포함하지 않은 2D 작품 원본 형태로 생성했다. 현재 파일은 시각 방향을 검증하는 `1086 × 1448px` 초안이며, 실제 A3 주문 전에는 선정작을 4K로 다시 생성하고 `3508 × 4961px`, 300PPI 인쇄 마스터로 제작해야 한다.

## 1. 금(金) 부족 — 고요한 재물 수렴

- 풍수 점수: 91
- 공간: 밝은 거실
- 문제: 화·수 기운이 빠르고 금 기운이 부족해 기회와 재물이 머물지 못함
- 처방: 둥근 수렴, 질서, 은빛 광물성, 차분한 심청색
- 컬렉션: 고요한 기운 / Quiet Element
- 작품 개념: 달빛의 그릇 / Moonlit Vessel
- 파일: `sample-01-metal-quiet-v1.png`

## 2. 수(水) 부족 — 관계와 정서의 순환

- 풍수 점수: 58
- 공간: 신혼 침실
- 문제: 토 기운이 무겁고 수 기운이 부족해 대화와 감정의 흐름이 정체됨
- 처방: 두 개의 독립된 흐름을 하나의 투명한 물결로 연결
- 컬렉션: 천체의 숨 / Celestial Current
- 작품 개념: 두 개의 조류 / Twin Tides
- 파일: `sample-02-water-harmony-v1.png`

## 3. 목(木) 부족 — 성장과 집중 회복

- 풍수 점수: 34
- 공간: 서재·업무 공간
- 문제: 금 기운이 과하고 목 기운이 부족해 경직·정체·진로 지연이 생김
- 처방: 상승하는 수직 리듬, 비취색, 한지와 목결의 촉감
- 컬렉션: 길상의 결 / Auspicious Grain
- 작품 개념: 첫 상승 / First Ascent
- 파일: `sample-03-wood-growth-v1.png`

## 다음 테스트

1. 세 작품 중 실물로 먼저 확인할 방향을 고른다.
2. 선택작의 구도는 유지하고 재질과 미세 디테일만 4K로 정교화한다.
3. A3 무광 파인아트지용 인쇄 마스터를 만든다.
4. 월넛 프레임과 무광 블랙 프레임 목업을 비교한다.
5. 실제 샘플 1개를 주문해 화면 대비 색·암부·질감을 확인한다.
