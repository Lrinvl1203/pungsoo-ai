# Linked Remedy Artwork + Guardian Object — 5 Samples

## Source prescription

- Remedy element: Earth
- Guardian: Dragon
- Energy mode: Circulate
- Artwork reference:
  `docs/samples/remedy-art/guardian-style-matrix-4x3/11-totem-dragon-earth-circulate.png`

These samples test a shared design-DNA pipeline. The object is not merely the
same animal as the artwork. It inherits the artwork's topology, palette order,
circulation voids, mineral texture, and brass junction accent.

## Shared design DNA

| Token | Artwork expression | Object expression |
|---|---|---|
| Guardian | Long modular dragon | Continuous low-poly dragon |
| Energy mode | Turning S circulation route | S-shaped load-bearing body |
| Flow junction | Carved rings and channels | Circular opening / negative space |
| Earth palette | Ochre, sage, ivory, terracotta, umber | Inlays, modules, or recessed lacquer in the same sequence |
| Material rhythm | Shallow mineral relief | Matte mineral resin or faceted shell |
| Junction accent | Small muted brass blocks | One small paintable brass seam |

## Samples

1. **Obsidian Earth Circuit** — strongest contrast and most collectible. The
   base is visually heavy, so the production CAD should reduce it.
2. **Ink + Clay Signal** — best overall first prototype. It feels contemporary,
   keeps the artwork relationship obvious, and has a stable one-piece outline.
3. **Mineral Block Guardian** — most literal one-to-one translation from the
   artwork. The small return curl currently reads as detached and must be fused
   before manufacture.
4. **Smoked Metal / Earth Inlay** — strongest premium and fashion positioning.
   The shell should remain smooth enough to avoid a mecha reading.
5. **Bone Ink Interior Edition** — best for bright, warm-minimal interiors and
   the broadest decor compatibility.

## Recommendation

Use sample 2 as the structural prototype and offer samples 4 and 5 as dark and
light finish editions:

- **Earth Ink**: matte charcoal shell with mineral color fields
- **Earth Metal**: satin smoked-metal shell with mineral lacquer inlays
- **Earth Bone**: limestone-ivory shell with graphite edges

The personalized colors should be derived from the remedy artwork. Neutral shell
finish may remain a customer choice.

## Production constraints

- Target finished height: 80–90 mm
- One watertight body with an integrated base
- Minimum feature and wall thickness: 2 mm after CAD conversion
- Recessed color fields: 0.4–0.8 mm deep for masking and hand painting
- No separate whiskers, horns, tail rings, or floating elements
- Verify center of gravity, support scars, drain holes if hollow, and paint
  access before ordering

The five images are generated concept mockups, not printable 3D meshes.
