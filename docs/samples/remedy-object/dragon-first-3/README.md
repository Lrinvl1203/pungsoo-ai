# PUNGSOO Desk Guardian — Dragon concept 3

생성일: 2026-07-28  
참조 이미지: 주문 샘플 `PUNGSOO-mini-art-nouveau-dragon-3x5-300dpi.png`

## 공통 제작 조건

- 완성 크기: 높이 70–78mm
- 용도: 탁상용 수호 오브제
- 출력: 레진 우선, 단색 시제품
- 구조: 평평한 받침과 연결된 일체형 솔리드
- 최소 시각 두께: 1.8–2.2mm 이상
- 금지: 분리 부품, 가는 수염, 떠 있는 장식, 바늘 같은 뿔, 깊은 언더컷
- 표면 방향: 무광 청자석 또는 따뜻한 사암 질감

## 01 Circulation Gate

원형 기운문을 S자 용이 감싸는 상징형. 세트 상품의 대표 이미지로 가장 강하지만,
8cm 출력에서는 수염·뿔·발톱과 내부 빈 공간을 추가로 단순화해야 한다.

## 02 Mountain Guardian

산세 위에 웅크린 수호룡. 낮은 무게중심과 넓은 받침으로 안정적이며,
한국적 풍수 서사가 가장 직접적으로 읽힌다. 머리 주변 돌출부 보강이 필요하다.

## 03 Flow Totem

두꺼운 흐름판 위에 용을 부조로 통합한 모놀리식 토템.
한 덩어리 구조라 첫 실물 출력에 가장 적합하며 FDM 전환도 쉽다.
첫 STL 제작 기준안으로 추천한다.

## 생성 프롬프트 방향

세 안 모두 주문 액자의 아르누보 수호룡 이미지를 `reference image`로만 사용했다.
용의 얼굴, S자 기운 흐름, 청자색·황토색 팔레트만 계승하고 평면 구도는 복제하지 않았다.
각 프롬프트에는 실제 7–8cm 출력, 일체형 구조, 평평한 받침, 최소 부재 두께,
돌출 장식 제한, 제품 촬영용 3/4 시점을 고정했다.
