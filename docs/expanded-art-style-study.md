# PUNGSOO 확장 화풍 스터디

기준일: 2026-07-27

## 1. 변경하지 않는 원칙

현재의 네 작품군은 PUNGSOO만의 핵심 상품이므로 삭제하거나 일반 화풍으로
대체하지 않는다.

| 시그니처 코드 | 작품군 |
|---|---|
| `guardian_abstract` | 은호 추상화 |
| `modern_minhwa` | 현대 민화형 |
| `ink_wash` | 수묵 여백형 |
| `geometric_totem` | 기하학적 토템형 |

모든 분석 결과는 네 작품군 중 하나로 만든 `PUNGSOO Signature`를 반드시
포함한다. 확장 화풍은 같은 처방을 집의 취향에 맞게 다시 번역한
`Interior Edition`으로 추가한다.

```text
한 개의 비방서
  ├─ PUNGSOO Signature: 기존 4개 중 자동 선정, 항상 제공
  └─ Interior Edition: 인테리어·취향에 맞는 확장 화풍, 선택 제공
```

이 구조는 풍수 특화 정체성을 보존하면서 액자 구매자가 자신의 집에 맞는
그림을 선택하게 한다.

## 3. 첫 출시 후보 8종

3. 아르데코 가디언
4. 미드센추리 가디언
5. 르네상스 명암화
6. 인상주의 대기화
7. 우키요에 가디언
8. 시네마틱 애니메이션 가디언

이 여덟 종은 고전, 모던, 레트로, 일본 문화, 애니메이션, 수공예 프린트
취향을 넓게 대표한다.

## 5. “특정 작가풍” 요청 처리

상업 상품은 작가 이름 자체를 스타일 옵션이나 상품명으로 사용하지 않는다.
사용자가 특정 작가나 스튜디오를 입력하더라도 이름을 이미지 프롬프트에
전달하지 않고 다음 시각 특성으로 분해한다.

```text
시대
+ 매체
+ 선의 성격
+ 색의 관계
+ 명암
+ 공간 깊이
+ 구도
+ 장식 밀도
+ 표면 질감
= 독자적 Style Fingerprint
```

예시:

| 사용자가 원하는 느낌 | 제품에서 사용하는 독자적 표현 |
|---|---|
| 유명 후기인상주의 화가 같은 강한 붓질 | 소용돌이치는 리듬의 두꺼운 임파스토, 보색 밤 팔레트 |
| 유명 아르누보 포스터 작가풍 | 유기적 채찍 곡선, 평면 식물 장식, 비대칭 포스터 구도 |
| 유명 일본 애니메이션 감독풍 | 손그림 배경, 맑은 대기 원근, 자연광, 절제된 셀 음영 |
| 유명 현대 팝 작가풍 | 고채도 평면색, 깨끗한 외곽선, 반복 장식, 대표 캐릭터·상징 제외 |
| 유명 초현실주의 작가풍 | 불가능한 공간, 길게 늘어진 그림자, 상징적 사물 대신 오행 형태 변환 |

작가의 대표 캐릭터, 특정 작품 구도, 서명, 반복 아이콘과 식별 가능한
상징은 사용하지 않는다. 목표는 모방이 아니라 구매자가 좋아하는 미감의
구성 요소를 PUNGSOO의 시각 언어로 재설계하는 것이다.

## 6. 확장 화풍의 공통 제한

어떤 화풍을 적용하더라도 다음은 유지한다.

- 부족 오행과 과잉 오행
- PURIFY, CIRCULATE, AMPLIFY 에너지 모드
- 동일한 수호동물
- 수호동물의 종 식별 단서
- 문자, 부적, 가짜 한자, 서명과 로고 금지
- 특정 기존 작품의 구도 복제 금지
- A3 인쇄 재단 안전 영역
- 액자와 오브제 사이의 실루엣 일관성

르네상스나 애니메이션 화풍에서도 인간 주인공을 넣지 않는다. 작품의
주인공은 수호동물과 오행의 흐름이다.

## 7. 상품 구조

### 단품

- `PUNGSOO Signature Frame`: 기존 4개 중 자동 선정
- `Interior Edition Frame`: 설치 공간과 취향에 맞춘 확장 화풍

### 세트

- `Guardian Diptych`: 동일 비방서의 시그니처와 인테리어 에디션 2점 세트
- `Frame + Totem`: 인테리어 에디션 액자와 같은 실루엣의 수호 오브제
- `Seasonal Reissue`: 같은 처방을 계절 팔레트와 다른 화풍으로 재발행

시그니처와 확장 에디션을 경쟁시키지 않고 컬렉션과 재구매 상품으로 만든다.

## 8. 사용자 화면

처음부터 26개 화풍 목록을 보여주지 않는다.

1. 설치 공간 사진을 분석한다.
2. PUNGSOO Signature 한 장을 먼저 확정한다.
3. 집과 어울리는 확장 화풍 3개만 추천한다.
4. 각 추천에 `왜 이 집과 어울리는지` 한 문장으로 설명한다.
5. 사용자는 시그니처 유지, 인테리어 에디션 선택, 2점 세트 중 하나를 고른다.

고급 사용자는 `더 많은 화풍 보기`에서 시대·매체·분위기 필터를 사용할 수
있다.


## 10. 테스트 계획

첫 테스트는 동일한 비방서 3건을 8개 확장 화풍으로 생성해 총 24장을 비교한다.

| 비방서 | 목적 |
|---|---|
| 목 부족·토끼·PURIFY | 부드러운 화풍의 정화 표현 검증 |
| 토 부족·용·CIRCULATE | 장식·고전 화풍의 흐름 검증 |
| 수 부족·쥐·AMPLIFY | 그래픽·애니 화풍의 방향성 검증 |

평가 항목:

- 수호동물 인식
- 풍수 처방 유지
- 해당 인테리어와의 조화
- 독자성
- 특정 작품·작가 모방 위험
- A3 인쇄 적합성
- 액자와 오브제 세트 전환 가능성
