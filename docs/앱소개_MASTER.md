## 3. 핵심 가치 제안 (UVP)

### 세계 최초의 "처방형 공간 예술" 서비스
기존 풍수/운세 앱은 **텍스트 진단으로 끝난다.**  
풍수지리 AI는 진단 결과를 바탕으로:

1. **진단** → 공간의 오행 불균형 수치화
2. **처방** → 부족한 기운을 보완하는 비방(符方) 도출
3. **예술화** → AI가 처방을 고해상도 아트워크로 생성
4. **실물화** → 해당 아트를 액자/3D 오브제로 제작·배송

**"이 그림을 방에 걸면 당신의 공간 기운이 바뀐다"**는  
동양철학적 명분과 인테리어적 실용성이 결합된 유일무이한 상품.

    │   ├── 비방화 원본 고해상도 (₩9,900)

    └── 실물 상품 (제작 + 배송)
        ├── 비방 아트 액자 (₩49,000)
        └── 비방 오브제 3D 프린팅 (₩79,000)

## 5. 5장 결과 리포트 상세

### 제1장 — 공간 기운 총평
- **풍수 점수**: 0~100점 수치화 (예: 73점 / 100)
- **전체 진단**: 길(吉) / 흉(凶) + 종합 코멘트
- **주요 특징**: 공간에서 감지된 풍수적 특성 3~5가지
- **대가 코멘트**: AI가 생성한 40년 대가 어투의 종합 조언

### 제2장 — 오행(五行) 분석
- **오행 점수**: 목(木)·화(火)·토(土)·금(金)·수(水) 각 0~100
- **부족 원소 진단**: 가장 취약한 오행 + 과잉 오행 도출
- **처방 방향**: 보완해야 할 기운과 색상·형태·소재 제안

### 제3장 — 공간 비방서 (空間秘方書) ⭐
- **형식**: A4 3페이지 분량 마크다운 리포트
- **구성**: 진단 요약 → 공간별 처방 → 비보 배치 가이드 → 실천 체크리스트
- **가격**: 별도 유료 (Polar 디지털 결제)
- **특징**: 즉시 다운로드 PDF 형태 제공

### 제4장 — 12간지 비방 설계도
- **내용**: 생년월일 기반 12간지(띠) 맞춤 오브제 설계
- **포함**: 오브제 형태, 소재, 색상, 배치 방향 처방
- **이미지**: fal.ai 생성 3D 렌더링 이미지
- **연결**: 해당 설계도 기반 실물 오브제 제작 의뢰 가능

### 제5장 — 비방화 (秘方畵) ⭐
- **내용**: AI가 생성한 공간 맞춤 디지털 비방 아트워크
- **처방 키워드**: 부족한 오행을 채우는 색상·패턴·상징 적용
- **아트 스타일**: 3종 선택
  - **모던(Modern)**: 미니멀·현대적, 인테리어 친화적
  - **레트로(Buddhist)**: 전통·복고풍, 동양화 감성
  - **모던+레트로**: 두 스타일의 퓨전
- **이미지 비율**: 1:1 / 9:16 / 16:9 / 3:4 / 4:3 / 직접입력
- **잠금 해제**: ₩9,900 결제 후 고해상도 원본 다운로드

## 11. 이미지 생성 아트 스타일 가이드

### `modern` — 모던 스타일
**컨셉**: 미니멀리즘 + 동양 오행의 현대적 재해석  
**특징**:
- 깔끔한 선, 여백 중시
- 오행 색상의 세련된 팔레트 적용
- 서구 추상화 + 동양 철학 상징 결합
- 인테리어 갤러리·화이트 박스에 어울리는 스타일

**이미지 프롬프트 키워드**:
`minimalist, clean lines, contemporary art, feng shui elements, abstract geometry, muted earth tones, gallery-worthy, modern interior`

---

### `buddhist` — 레트로 스타일  
**컨셉**: 전통 불교/도교 회화 + 복고 감성  
**특징**:
- 전통 한국화·중국화 기법
- 연꽃·산수·선(禪) 상징 모티프
- 낡은 종이 질감, 먹(墨) 느낌
- 전통 사찰·한옥 인테리어에 어울리는 스타일

**이미지 프롬프트 키워드**:
`traditional Korean/Chinese ink painting, lotus flower, mountain landscape, Zen aesthetic, aged paper texture, vintage Buddhist art, calligraphy brush strokes`

---

### `modern_buddhist` — 모던+레트로 퓨전
**컨셉**: 전통 동양 상징의 현대적 재해석  
**특징**:
- 전통 문양 + 미니멀 레이아웃
- 수묵화 터치 + 현대 색상
- 팝아트적 동양화 감성
- 젊은 세대 타겟 힙한 인테리어

**이미지 프롬프트 키워드**:
`contemporary interpretation of traditional Asian art, fusion of ink painting and modern design, reinterpreted feng shui symbols, Neo-traditional style, bold colors with calligraphic elements`

## 14. 특수 기능

1. **대가 소개**: 40년 대가 AI 시스템 소개
2. **서비스 소개**: 풍수 진단 → 비방화 → 실물 제작 플로우
3. **명인 소개**: 서비스에 참여한 풍수 명인 소개
