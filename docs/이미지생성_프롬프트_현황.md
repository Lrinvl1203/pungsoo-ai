## 1. 비방화 (Remedy Art) — `type: 'remedy'`

### 최종 fal.ai 전송 프롬프트 (템플릿)

```
Create a high-quality portrait artistic talisman/digital art based on this concept: {image_generation_prompt}.

Design Style Instructions: {styleKeywords}.

The image must be suitable for a mobile wallpaper or framed wall art. High resolution, 8k.
```

---

### 스타일별 styleKeywords

#### `modern` (기본값)
```
Modern Abstract Art style, minimalist, aesthetic, spiritual, 3D render, luxurious texture, cinematic lighting
```

#### `buddhist` (레트로)
```
Traditional Buddhist Art style, Thangka painting aesthetic, Zen spirituality, golden aura, intricate mandala patterns, temple atmosphere, divine and sacred look
```

#### `modern_buddhist` (모던+레트로)
```
Fusion of Modern Minimalist and Buddhist Art, sophisticated zen aesthetics, subtle golden lotus or mandala motifs in abstract geometry, contemporary spiritual art, clean lines, meditative atmosphere, gallery quality
```

---

### `{image_generation_prompt}` 생성 방식

`image_generation_prompt` 값은 Gemini AI가 풍수 분석 결과를 바탕으로 자유 생성.  
`server/constants.ts` 시스템 프롬프트에서 아래와 같이 지시:

```
"remedy_art": {
  "deficiency": "부족한 오행 기운 (예: 금(Metal) 기운 부족)",
  "solution_keyword": "아트 컨셉 키워드",
  "image_generation_prompt": "예술적 이미지 생성을 위한 영문 프롬프트",
  "art_story": "이 예술 작품이 왜 처방되었는지에 대한 대가의 도슨트 설명"
}
```

> ⚠️ **현재 구조의 한계**: Gemini가 `image_generation_prompt`를 자유 생성하므로  
> 오행별 필수 색상·형태 키워드가 누락될 수 있음.

---

### 사용 모델
- `fal-ai/bytedance/seedream/v4.5/text-to-image`
- 이미지 비율: 사용자 선택값 (기본 `portrait_4_3`)

| 사용자 선택 | fal.ai image_size |
|------------|-------------------|
| 1:1 | `square_hd` |
| 9:16 | `portrait_16_9` |
| 16:9 | `landscape_16_9` |
| 4:3 | `landscape_4_3` |
| 3:4 | `portrait_4_3` |
| 직접입력 | `{ width: N, height: N }` |

## 2. 12간지 오브제 — `type: 'zodiac'`

### 최종 fal.ai 전송 프롬프트 (템플릿)

```
A full-body 3D low-poly geometric sculpture of a {animal} for modern interior decor. Placed in a majestic pose. Crafted from luxurious {material_and_color}. Special feature: {specific_pose_or_feature}. High-end minimalist art object photography, professional studio lighting with dramatic reflections, clean neutral background, 8k resolution, C4D Arnold render style, ready for 3D printing aesthetic.
```

---

### 변수 설명 (Gemini가 `zodiac_remedy_object`에 생성)

| 변수 | 설명 | 예시 |
|------|------|------|
| `{animal}` | 12간지 동물 종 | 호랑이, 돼지, 용, 말 |
| `{material_and_color}` | 오행 맞춤 재질 + 색상 | 붉은색 나무 조각, 매트 화이트 세라믹, 금빛 금속 |
| `{specific_pose_or_feature}` | 특정 자세·특이사항 | 입에 동전을 물고 앞발을 들고 있는 포즈 |

### `zodiac_remedy_object` Gemini 생성 지시 (constants.ts)

```
"zodiac_remedy_object": {
  "animal": "동물 종 (예: 호랑이, 돼지 등)",
  "material_and_color": "오행에 맞춘 재질과 색상 (예: 붉은색 나무 조각, 매트 화이트 세라믹 등)",
  "specific_pose_or_feature": "특정 자세나 추가 특이사항 (예: 입에 동전을 물고 앞발을 들고 있는 포즈)",
  "reason": "왜 이 동물의 이 재질, 이 자세가 이 공간에 완벽한 처방이 되는지에 대한 도사님의 깊이 있는 해석",
  "placement_guide": "배치 위치 가이드 (예: 거실의 남동쪽 모서리에 머리 방향이 현관을 향하게 배치)"
}
```

### 사용 모델
- `fal-ai/bytedance/seedream/v4.5/text-to-image`
- 이미지 비율: `square_hd` 고정

## 3. To-Be 공간 이미지 — `type: 'to-be'`

### 최종 fal.ai 전송 프롬프트 (템플릿)

```
Look at Figure 1. Modify this room image by adding these interior items naturally into the scene: {itemsText}. Maintain the EXACT same camera angle, room structure, walls, floor, and existing furniture. Only add the new items in appropriate locations. Style: Photo-realistic interior design photography, natural lighting.
```

### `{itemsText}` 생성 방식
`solution_items` 배열을 아래 형식으로 join:
```
{item_name} ({placement_guide}), {item_name} ({placement_guide}), ...
```

예시:
```
청동 거울 (현관 정면 벽에 눈높이로 배치), 대나무 화분 (창문 왼쪽 모서리), ...
```

### 사용 모델
- `fal-ai/bytedance/seedream/v4.5/edit` (img2img 편집 모델)
- 이미지 비율: `landscape_4_3` 고정
- 입력: 원본 공간 사진 (fal storage에 업로드 후 URL 전달)

## 전체 흐름 요약

```
[Gemini 분석 API]
  ├── remedy_art.image_generation_prompt  ──→  비방화 프롬프트 재료
  └── zodiac_remedy_object.{animal, material_and_color, specific_pose_or_feature}  ──→  오브제 프롬프트 재료

[generate-visuals API]
  ├── type: remedy
  │     └── "Create a high-quality portrait artistic talisman... {prompt} ... {styleKeywords} ... 8k"
  │         → fal-ai/seedream/v4.5/text-to-image (비율 선택 가능)
  │
  ├── type: zodiac
  │     └── "A full-body 3D low-poly geometric sculpture of a {animal}..."
  │         → fal-ai/seedream/v4.5/text-to-image (square_hd 고정)
  │
  └── type: to-be
        └── "Look at Figure 1. Modify this room image by adding..."
            → fal-ai/seedream/v4.5/edit (img2img, landscape_4_3 고정)
```
