## 변경 규칙

새 결정을 추가할 때 다음을 기록한다.

1. 날짜와 고유 ID
2. `ACTIVE`, `LOCKED`, `DESIGNED`, `NEXT`, `LATER`, `DEFERRED`,
   `BLOCKED`, `EXCLUDED`, `SUPERSEDED` 중 하나의 상태
3. 무엇을 결정했는지
4. 왜 결정했는지와 검증 근거
5. 기존 결정을 대체하면 대체 대상 ID
