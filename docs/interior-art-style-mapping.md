# 인테리어 × 비방화 화풍 매핑

기준일: 2026-07-27

## 1. 현재 작품군

현재 앱은 사용자가 화풍을 고르지 않고 비방서의 목적과 공간에 따라 다음
4개 작품군을 자동 선택한다.

| 코드 | 현재 표시명 | 주요 용도 |
|---|---|---|
| `guardian_abstract` | 은호 추상화 | 일반 거실·서재, 순환형 기본값 |
| `modern_minhwa` | 현대 민화형 | 가족·관계·선물, 수호동물 서사 |
| `ink_wash` | 수묵 여백형 | 침실·명상·정화·회복 |
| `geometric_totem` | 기하학적 토템형 | 업무·사업·상업 공간·3D 오브제 연계 |

현재 자동 라우팅은 처방 의미에는 적합하지만 실제 설치할 집의 가구, 벽,
바닥, 조명과 취향은 반영하지 않는다.

## 2. 새 구조: 처방과 인테리어 외관 분리

```text
비방서
  ├─ 처방 코어: 부족 오행, 과잉 오행, 에너지 모드, 수호동물
  └─ 설치 공간: 인테리어 프로필, 벽색, 가구색, 소재, 조명
          ↓
작품군 선택
  + 색조 변환
  + 질감·밀도 조절
  + 액자·매트 추천
          ↓
안전한 조화안 + 강한 포인트안
```

오행색과 수호동물은 처방 변수이므로 유지한다. 사용자의 인테리어는 같은
색을 얼마나 밝고 어둡게, 선명하거나 탁하게, 평면적이거나 질감 있게
표현할지를 결정한다.

## 4. 처방 모드와 인테리어 매핑 우선순위

### PURIFY

기본 작품군은 수묵 여백형 또는 은호 추상화다.

- 미니멀·오가닉·코스탈: 넓은 여백과 낮은 대비 유지
- 럭셔리·산업형: 검정 면적을 줄이고 광택 대신 무광 질감 사용
- 맥시멀: 패턴 수를 제한하고 한 개의 조용한 비움 영역 확보

### CIRCULATE

기본 작품군은 은호 추상화 또는 현대 민화형이다.

- 미드센추리·럭셔리: 곡선과 기하 모듈의 연결을 강조
- 클래식·코리안: 동물과 오행 흐름을 하나의 평면 서사로 구성
- 스칸디나비안: 동물 인식을 유지하되 장식 밀도를 낮춤

### AMPLIFY

기본 작품군은 기하 토템형 또는 현대 민화형이다.

- 업무·상업 공간: 기하 토템형과 강한 방향성
- 선물·개인 서사: 현대 민화형과 높은 수호동물 인식
- 침실 설치: 증폭형이라도 대비와 전진감을 한 단계 낮춤

처방 모드와 인테리어가 충돌하면 처방을 버리지 않는다. 같은 작품군 안에서
대비, 채도, 밀도와 동물 가시성을 조절한다.

## 5. 오행 팔레트와 인테리어 톤 결합

오행별 핵심 색군은 유지한다.

| 오행 | 핵심 색군 |
|---|---|
| 목 | 비취, 소나무색, 셀라돈, 따뜻한 아이보리 |
| 화 | 절제한 주사, 산호, 테라코타, 호박색 |
| 토 | 황토, 모래, 점토, 세이지, 엄버 |
| 금 | 석회 아이보리, 은회색, 흑연, 절제한 황동 |
| 수 | 인디고, 코발트, 청록, 셀라돈, 은회색 |

인테리어 프로필은 다음처럼 색의 톤만 변환한다.

| 톤 변환 | 적용 프로필 |
|---|---|
| 밝게, 저채도, 여백 확대 | 따뜻한 미니멀, 스칸디나비안, 코스탈 |
| 따뜻하게, 광물·흙 질감 강화 | 오가닉 모던, 코리안, 클래식 |
| 중명도, 복고색 대비 | 미드센추리 |
| 어둡게, 흑연·황동 포인트 | 럭셔리, 어반 다크 |
| 채도·패턴·동물 인식 강화 | 볼드 에클레틱 |

예를 들어 같은 화 기운 처방이라도:

- Japandi 집: 옅은 테라코타와 따뜻한 한지 여백
- Mid-century 집: 번트 오렌지와 청록의 평면 기하
- Luxury 집: 깊은 주사색, 흑연과 무광 황동의 절제된 대비

가 된다.

## 6. 사용자 입력 UX

### 권장 방식

사용자에게 20개 화풍 목록을 보여주지 않는다.

1. 작품을 걸 실제 벽 사진을 선택적으로 받는다.
2. AI가 인테리어 프로필과 벽·가구·바닥의 주요 색을 추정한다.
3. 사용자에게 추정한 프로필 한 개와 대체 프로필 두 개만 보여준다.
4. 최종 결과는 두 장으로 제안한다.
   - `조화안`: 공간에 자연스럽게 녹아드는 작품
   - `포인트안`: 같은 처방을 유지하면서 더 강하게 보이는 작품

내부 분석 사진과 실제 액자 설치 공간이 다를 수 있으므로 `분석할 공간 사진`과
`액자를 걸 벽 사진`은 별도 입력으로 취급한다. 외부 입지 분석 사용자에게도
액자 설치 공간 사진을 선택적으로 받을 수 있어야 한다.

### 사진이 없는 경우

10개 전문 명칭 대신 다음 5개 질문으로 분류한다.

1. 집이 밝은 편인가, 어두운 편인가?
2. 가구는 밝은 나무, 진한 나무, 금속 중 무엇이 많은가?
3. 공간이 단정하고 비어 있는가, 장식과 패턴이 많은가?
4. 차분한 그림과 강한 포인트 그림 중 어느 쪽을 원하는가?
5. 한국적인 느낌을 은은하게 원하는가, 분명하게 원하는가?

## 7. 경우의 수

사용자에게는 10개 인테리어 프로필과 각 2개 결과만 보여주지만 내부 생성
경우의 수는 다음과 같다.

```text
인테리어 프로필 10
× 조화안/포인트안 2
× 오행 5
× 에너지 모드 3
× 수호동물 12
= 3,600개 의미 있는 기본 조합
```

액자 마감 3종까지 포함하면 10,800개 상품 조합이 가능하다. 모든 이미지를
미리 만들 필요는 없고 같은 메타 프롬프트 엔진에서 변수로 생성한다.

## 8. 액자와 오브제의 세트 매핑

| 인테리어 프로필 | 액자 마감 | 오브제 마감 |
|---|---|---|
| 따뜻한 미니멀 | 내추럴 오크 | 광물성 백색·점토색 |
| 오가닉 모던 | 화이트 오크 | 사암·테라코타 |
| 스칸디나비안 | 자작나무 | 밝은 무광색 |
| 코리안 컨템퍼러리 | 월넛·먹빛 우드 | 먹빛·도자 백색 |
| 미드센추리 | 중간 톤 월넛 | 적갈·청록·황토 |
| 컨템퍼러리 럭셔리 | 매트 블랙·다크 월넛 | 흑연·절제한 황동 |
| 어반 다크 | 블랙 메탈 | 차콜·산화 금속 |
| 클래식 엘레강스 | 다크 월넛 | 브론즈·짙은 광물색 |
| 에어리 코스탈 | 화이트 오크 | 모래색·셀라돈 |
| 볼드 에클레틱 | 월넛·컬러 래커 | 포인트 컬러 무광 |

액자와 오브제는 같은 수호동물, 오행, 인테리어 톤을 공유한다. 액자에는
동물의 전체 흐름을, 오브제에는 같은 흐름에서 추출한 실루엣과 명판을 사용해
한 세트라는 인상을 만든다.

- [ ] 조화안·포인트안 두 후보 생성
- [ ] 작품군 선택 뒤 인테리어 톤 변환 적용
- [ ] 프로필별 액자·매트·오브제 마감 추천
- [ ] 주문 데이터에 인테리어 프로필과 마감 저장
- [ ] 실제 공간 합성 목업 생성

## 10. 시장 근거

Etsy의 2026년 봄·여름 보고서는 wall art decor, gallery prints와 abstract
art 검색 증가를 소개하고, 서로 어울리는 시리즈와 실제 공간 목업, 명확한
크기 안내를 권한다. Houzz의 2025년 자료는 따뜻한 오가닉 모던, 개인화,
맥시멀 레이어와 과감한 색상처럼 서로 반대되는 취향이 동시에 존재함을
보여준다. 따라서 하나의 고정 화풍보다 처방 코어를 유지한 인테리어별 외관
변환이 적합하다.
