# 비방화 자동 스타일 적용

## 적용 결과

기존의 `모던 / 레트로 / 모던+레트로` 사용자 선택을 제거하고 비방서가 작품군을 자동 결정하도록 변경했다.

```text
사용자 고민
  → PURIFY / CIRCULATE / AMPLIFY
부족·과잉 오행
  → 색·재료·형태장
수호동물
  → 큰 몸선 + 종별 단서
공간과 목적
  → 은호 추상화 / 현대 민화 / 수묵 여백 / 기하 토템
  → 최종 프롬프트 + 의미 누출 방지 + 생성
```

## 라우팅 기본값

| 조건 | 작품군 |
|---|---|
| 침실·휴식·회복 또는 PURIFY | 수묵 여백형 |
| 가족·관계·선물 | 현대 민화형 |
| 사업·업무·상업 공간 또는 AMPLIFY | 기하학적 토템형 |
| 그 외 CIRCULATE | 은호 추상화 |

## 구현 파일

- `utils/remedyArt.ts`: 오행 정규화, 에너지 동작, 작품군 선택, 동물 가시성, 최종 메타 프롬프트
- `api/generate-visuals.ts`: 기존 화풍 키워드 대신 자동 메타 프롬프트 사용
- `services/geminiService.ts`: 전체 비방 문맥을 이미지 API에 전달
- `components/AnalysisForm.tsx`: 사용자 화풍 선택 제거
- `components/RemedyCard.tsx`: 자동 선정된 작품군·에너지·수호동물 표시
- `pages/MyPage.tsx`: 스타일 선호 설정 제거
- `server/constants.ts`: 부족 오행 후보 → 띠 충 회피 → 공간 목적 순서의 수호동물 선정 규칙

## 의미 누출 방지

기존 분석 AI가 달, 산, 동전, 그릇처럼 직접적인 사물을 프롬프트에 넣더라도 이미지 생성기는 이를 서사 참고로만 사용한다. 실제 작품에는 오행색, 형태 위상, 수호동물 자세로 번역하며 문자 그대로의 사물을 그리지 않는다.

## 검증

대표 시나리오 세 건을 실행했다.

| 사례 | 결과 |
|---|---|
| 목 부족·수 과다·숙면·침실·토끼 | PURIFY → 수묵 여백형 |
| 토 부족·금 과다·가족 관계·거실·용 | CIRCULATE → 현대 민화형 |
| 수 부족·토 과다·사업·업무실·쥐 | AMPLIFY → 기하학적 토템형 |

한자 단독 오행 표기 `木火土金水`도 정규화하며, 프로덕션 Vite 빌드를 통과했다.
