# 첫 액자 실물 테스트 출력 패키지

## 선정 작품

- 작품군: 현대 민화형
- 비방: 목(木) 정화
- 은호: 토끼
- 선정 이유: 4개 작품군 가운데 개인화 서사가 가장 즉시 전달되고, 일반 고객이 액자 상품으로 이해하기 쉽다.
- 원본: `docs/samples/remedy-art/guardian-style-matrix-4x3/04-minhwa-rabbit-wood-purify.png`

## 제작 사양

- 재단 크기: A3, 297 × 420 mm
- 도련: 사방 3 mm
- PDF 페이지: 303 × 426 mm
- 래스터 마스터: 3579 × 5031 px
- 해상도 메타데이터: 300 DPI
- 색 공간: RGB, sRGB ICC 포함
- 권장 용지: 무광 파인아트지 210–260 gsm 또는 매트 코튼지
- 권장 액자: 얇은 내추럴 오크 또는 매트 월넛, 유광 금색 몰딩 제외
- 권장 표면: 반사 방지 아크릴 또는 무광 코팅

## 주문 전 확인

이 패키지는 1086 × 1448 생성 원본을 Lanczos 방식으로 보수적으로 확대하고 약한 출력 샤프닝을 적용한 첫 실물 테스트용이다. 인쇄 품질을 평가할 때 다음을 확인한다.

1. 토끼 외곽선에 계단 현상이나 과한 샤프닝 테두리가 없는가
2. 짙은 녹색 면의 한지 질감이 뭉개지지 않는가
3. 상아색 배경이 노랗거나 회색으로 치우치지 않는가
4. 가는 금빛 경계가 끊기거나 번지지 않는가
5. 1–2 m 거리에서 토끼와 상승 흐름이 함께 읽히는가

실판매 마스터는 가능하면 생성 단계부터 장변 4K 이상으로 확보하거나 전용 초해상도 모델을 거쳐 같은 규격으로 다시 제작한다.
